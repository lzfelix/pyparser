# Decision records

Short records of design decisions and why they were made, so they don't have to be re-derived later.

Each record is a numbered file that is never renumbered. When a decision changes, add a new record that supersedes the old one, and update the old record's status, rather than rewriting it.

| # | Decision | Status |
|---|----------|--------|
| [0001](0001-operations-use-pattern-matching-instead-of-visitors.md) | Operations use pattern matching instead of the visitor pattern | Accepted |
| [0002](0002-symbolic-differentiation-instead-of-dual-numbers.md) | Symbolic differentiation instead of dual numbers | Accepted |
| [0003](0003-constants-are-resolved-at-evaluation-time.md) | Constants are resolved at evaluation time | Accepted |
| [0004](0004-expression-wrapper-api.md) | An immutable `Expression` wrapper as the user-facing API | Accepted |
| [0005](0005-local-rewrite-simplifier.md) | A local-rewrite simplifier, without a normal form | Accepted |
